# 숲 테마 시작 메뉴 · 설정창

첨부 시안을 기존 UGUI에 적용한다. 좌우 분할 이미지를 붙이는 대신 시작 화면과 설정 팝업이라는 두 상태로 만든다.

## 배치와 소유 씬

- MainMenu: 전체 화면 숲 배경 → 명암 오버레이 → 중앙 제목 SF_ADVENTURE와 장식선 → Start / Settings / Exit 세로 버튼 → 하단 문구.
- CoreScene: 전체 화면 입력 차단 배경 → 중앙 설정 패널 → SETTINGS 제목과 닫기 → Audio 행 → Display 행들 → Back / Apply.
- 새 설정 패널은 MainMenu의 Settings 버튼으로 연다. 게임 중 ESC로 여는 기존 창은 별도로 유지한다.
- 기존 Player HUD와 Player 등록 동작은 유지한다.

## 표현

- 기준 해상도 1920×1080, CanvasScaler의 Scale With Screen Size 사용.
- 중앙 콘텐츠는 최대 폭을 제한하고 배경만 화면에 맞춰 채운다.
- 짙은 녹색 반투명 패널, 아이보리 글자, 올리브색 테두리, 연두색 선택 강조.
- 제목에는 세리프 계열, 설정 항목에는 읽기 쉬운 산세리프 계열 글꼴.
- 숲 배경과 잎 장식은 별도 아트로 준비한다. 텍스트·버튼·슬라이더를 배경 이미지에 합치지 않는다.

## 재사용

- MainMenuButtons의 챕터 시작, 설정 열기, 게임 종료 기능.
- UIManager의 설정창 표시와 스태미나 HUD 연결.
- VolumeSlider의 0~1 값과 로그 기반 Master 볼륨 제어.

## 승인된 기능 범위

전체 기능: Brightness / Resolution / Fullscreen / Apply까지 구현. Apply는 설정 저장, Back·닫기는 미적용 변경 취소로 통일한다. 새 설정창이 이미 열린 상태에서 ESC는 닫기만 한다. 게임 중 ESC 창의 외형과 동작은 변경하지 않는다. InputReader는 수정하지 않는다. 밝기는 디스플레이 하드웨어 밝기가 아닌 게임 화면 보정이다.

## 확인 기준

- 16:9와 16:10에서 배치와 글자 잘림 확인.
- Start 진입, ESC 열기·닫기, 배경 버튼 입력 차단, 음량 조절 확인.
- 전체 기능 선택 시 화면 설정 적용·취소·재시작 후 복원 확인.
- Unity 컴파일과 실제 화면을 확인하기 전에는 구현 완료로 보고하지 않는다.

현재 세션에 Unity MCP 연결은 없다. 실제 씬 적용·실행 검증에는 사용 가능한 다른 에디터 접근 방법 또는 사용자 확인이 필요하다.
