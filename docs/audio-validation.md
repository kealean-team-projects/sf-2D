# 오디오 적용 검증 — 2026-09-26

## 추가 변경: 좌우 전환 및 착지음 겹침

사용자의 감지 거리(이동음 3, 착지음 3.5)로 반복적인 낙하·좌우 전환을 재현했을 때 이동 효과음이 동시에 여러 개 재생되는 검증이 실패했다. 착지음이 추적되지 않고 누적되면서 반복 발소리와도 겹치는 경로를 확인했다.

PlayerAudio가 착지음 핸들을 보관하고 이전 이동 소리를 정리하도록 수정했다. 착지음 재생 중에는 발소리를 억제한다. Footstep Resume Window=0.12초를 추가해 짧은 방향 전환 정지는 무음 일시정지 후 같은 소스로 이어 재생한다. 기존 사용자의 감지 거리와 최소 추락 시간은 유지했다.

수정 후 전체 컴파일 오류 0개. 기존 실패 사례, 즉시 무음 일시정지, 같은 발소리 소스 재사용을 포함해 격리 Unity 검증 **60개 통과**. 실제 맵을 직접 플레이하며 청취하는 검증은 수행하지 않았다.

## 추가 변경: 이동음 감지 거리

PlayerAudio의 Footsteps에 Footstep Detection Distance를 추가하고 프리팹 값을 0.1 Unity 단위로 설정했다. 착지음 거리 0.15와 최소 추락 시간 0.5는 유지했다. 확장된 바닥 감지로 Walk/Run과 돌바닥 변형을 선택하며, 이동 입력과 실제 변위 조건은 유지한다. 물리 접지는 변경하지 않고 상승 중에는 확장 감지를 사용하지 않는다.

전체 코드 컴파일 오류 0개. 작은 바닥 틈에서 걷기/달리기, 거리 0에서 기존 동작 복구, 상승 중 억제, 범위 밖 무음 검증을 추가하여 격리 Unity 검증 **총 57개 통과**. 실제 음원 청취를 통한 최종 거리 조정은 수행하지 않았다.

## 추가 변경: 착지음 감지 거리

PlayerAudio에 Landing Detection Distance를 추가했다. 프리팹 값은 0.15 Unity 단위이며, 사용자가 변경한 Minimum Fall Time=0.5는 보존했다. 기존 발밑 질의만 아래로 확장하며 실제 Collider/IsGround는 바꾸지 않는다. 착지 전에 재생했으면 접촉 시 중복 재생을 막는다.

전체 컴파일 오류 0개. 기존 검증에 착지 전 재생, 실제 접지/발소리 판정 불변, 실제 접촉 중복 방지, 최소 추락 시간 유지, 거리 0에서 조기 재생 해제 및 접촉 시 재생, 상승 중 재생 방지를 추가해 격리 Unity 검증 **총 52개 통과**. 실제 음원 청취를 통한 지연 보정값 확정은 수행하지 않았다.

## 추가 변경: 착지음 최소 추락 시간

PlayerAudio의 Inspector에 Minimum Fall Time(초)을 추가하고 Player 프리팹의 기본값을 0.2초로 설정했다. 하강한 물리 스텝만 누적하며 상승·등반·리스폰은 제외한다. 0은 기존처럼 모든 착지를 허용한다.

변경 후 전체 코드 컴파일 오류 0개, 경고 12개. 격리 Unity 검증은 기존 25개에 짧은 추락 억제, 긴 추락 재생, 상승 제외, 등반 제외, 리스폰 초기화, 임계값 도달 시 재생을 추가하여 **31개 모두 통과**했다. 아래는 최초 적용 당시 기록이다.

## Unity에서 확인한 동작

1. 없는 사운드 요청은 오브젝트를 만들지 않는다.
2. 반복 소리 한 개를 정지해도 다른 소리는 유지된다.
3. StageAudio 시작 시 BG_1을 재생한다.
4. 같은 소유자의 같은 BGM 요청은 다시 시작하지 않는다.
5. 다음 스테이지는 BG_2로 교체하며 이전 음악은 겹치지 않는다.
6. 이전 스테이지 종료는 새 스테이지의 음악을 끄지 않는다.
7. 현재 스테이지 비활성화 시 음악 정리, 재활성화 시 재생한다.
8. 초기 지상 생성은 착지음을 내지 않는다.
9. 기본 걷기/달리기와 돌바닥 걷기/달리기 소리가 선택된다.
10. BGM과 발소리를 동시에 재생한다.
11. 입력이 있어도 실제 변위가 없으면 발소리가 멈춘다.
12. 지면에 지지된 상태의 수직 속도만으로 발소리를 끄지 않는다.
13. 공중 상태는 발소리를 멈춘다.
14. 돌바닥 착지음은 한 번만 재생된다.
15. 위치 복구/사망/리스폰에서 착지 오작동을 억제하고 발소리가 복귀한다.
16. 일시정지는 발소리를 멈추며 BGM을 정지하지 않는다.
17. 전역 AudioListener.pause 동안 일회성 소리를 보존한다.
18. 실제 재생 완료 후 일회성 소리를 정리하고 남은 소스가 없다.

위 항목은 세부 단언 25개로 검증했다. 테스트는 운영 SoundManager, SoundListSo, Mover, PlayerAudio, FootstepSurface, StageAudio 소스를 그대로 복사해 Unity에서 실행했다. Player의 입력/생존 상태만 최소 대역으로 제공했다. 전체 운영 코드와의 타입 연결은 별도 전체 컴파일로 확인했다.

## 재현용 로컬 산출물

- `.utmp/audio-smoke/`: 독립 Unity 검증 프로젝트. 원본 작업 씬을 열거나 저장하지 않는다.
- `.utmp/audio-smoke/results.txt`: 25개 단언의 결과.
- `.utmp/audio-smoke/editor.log`: Unity 실행 로그.
- `AudioVerification.csproj`: 새 소스 파일을 포함한 전체 컴파일용 임시 프로젝트.

임시 산출물은 Git 제외 경로에 있다. Unity 검증 프로젝트의 `AudioSmokeEntry.Run`을 batchmode로 실행하면 결과를 재생성할 수 있다.

## 확인하지 않은 사항

실제 FirstMap/SecondMap 전체 수동 플레이, 실제 음원 청취 및 음악/효과음 볼륨 밸런스는 확인하지 않았다. 바닥 아트 의도와 Stone 표식의 최종 일치는 맵에서 확인한다. 개별 AudioSource.Pause/UnPause 지원은 이번 적용 범위가 아니다.
